# CARROSSEIS — registro das peças geradas

Uma ficha por carrossel gerado, mesmo os que nunca foram publicados. Formato em
`.claude/skills/carrossel-viral/references/ficha-carrossel.md`.

Nome do arquivo: `{AAAA-MM-DD}-{CLIENTE}-{slug-curto}.md`

## Por que isso existe

Parece burocracia. É o contrário: é o único lugar de onde saem as duas coisas que
importam depois.

| Uso | Quem consome | Prazo |
|---|---|---|
| Relatório semanal do cliente | O cliente | Toda segunda |
| Calibração de padrões por nicho | A skill `carrossel-viral` | Com volume |

Sem esse registro, daqui a quatro meses existirão dezenas de carrosséis publicados e
**nenhuma forma de saber o que funcionou**. É o passo que todo mundo pula e é o que
faz o sistema compor valor em vez de só produzir peça.

## A chave

O campo `media_id` liga a peça ao desempenho que a Meta devolve. Sem ele a ficha é
um arquivo morto. Preencher assim que publicar.
